# التحقق النهائي من معرض المشاريع

تاريخ الفحص: **9 أكتوبر 2026**. النطاق: معرض 33 مشروعاً، 33 صفحة تفصيلية، ومعاينات الصفحة الرئيسية. تفاصيل مصادر الصور وحدود تشغيل التطبيقات الأصلية في [CAPTURE_NOTES.md](CAPTURE_NOTES.md).

## بيئة الفحص والمسار

تم تقديم مجلد `dist` مباشرة على `http://localhost:8300` لاختبار ملفات HTML الفعلية التي ستُنشر إلى GitHub Pages. استُخدم Chromium وPlaywright؛ **Browser plugin not available** في الجلسة. المقاسات الأساسية: 1440×1000 و390×844، مع فحص عرض 320px والحركة المخففة. لم يُختبر Safari أو Firefox.

المسار المختبر: دخول المعرض ← البحث والتصنيف ← صفحة المشروع ← تبديل الكمبيوتر والجوال ← التنقل والتكبير والإغلاق ← المشروع التالي أو التواصل من الصفحة الرئيسية.

## مراجعة التصميم والمقارنة البصرية

تم فتح المراجع الثلاثة وصور التنفيذ بواسطة `view_image` في مراجعة التسليم نفسها. هذه المراجع تصورات لتصميم الموقع؛ **لم تُستخدم صور واجهاتها المتخيلة داخل المعرض**. تمت مقارنة التنفيذ بالمراجع والتحقق من وفائه بالاتجاه البصري مع الفروق المقصودة أدناه.

## الحدود والنشر

- الصور بيانات تجريبية ضمن الواجهات الأصلية، وبعض التطبيقات تحتاج تعديلات تشغيل محلية أو استجابات API تجريبية. لا يُثبت هذا الاختبار تشغيل الدفع أو الذكاء الاصطناعي أو البث والخدمات الخارجية في التطبيقات الأصلية.
- فحص عدم التكرار يعتمد بصمة PNG الأصلية؛ راجعت كذلك مجموعات اللقطات بصرياً واستبدلت الشاشات المكررة أو العالقة. لا تُحسب المصغرات صوراً مستقلة.
